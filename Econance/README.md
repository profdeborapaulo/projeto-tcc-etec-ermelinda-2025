# Econance
O Econance é um sistema de controle financeiro digital familiar e microempresarial. Com base em pesquisas exploratórias, quantitativas, descritivas e bibliográficas, foi possível identificar uma carência da população na eficiência e rapidez na hora de gerir seus gastos. 
# Funcionalidades
Automatizar o registro de despesas
Interpretar notas fiscais
Gerar relatórios detalhados dos gastos
Processar informações bancárias e dados inseridos pelo usuário
# Tecnologias Utilizadas
Framework - Flutter

Linguagem - Dart

Database: Firebase

GitHub para versionamento
# Como Executar o Projeto
1. Instale o flutter em sua máquina. Instruções em https://docs.flutter.dev/get-started.
2. Instale os pacotes de integração com o firebase. Instruções em https://firebase.google.com/docs/flutter/setup?platform=android.
3. Clone o repositório na IDE de sua preferência.
4. Rode o aplicativo em seu celular ou em um AVD.
