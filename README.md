# Projeto TCC: Trabalho de Conclusão de Curso em Desenvolvimento de Sistemas

-----

## Sobre o Projeto

Este repositório contém o trabalho de conclusão de curso desenvolvido por nosso grupo. O objetivo é apresentar o projeto de desenvolvimento de um sistema completo, incluindo código-fonte, documentação, scripts de banco de dados e material de apresentação.

-----

## Estrutura do Repositório

Para garantir a padronização e facilitar o acesso a todos os materiais do projeto, a estrutura de pastas e arquivos deve seguir o formato abaixo.

```
/nome-do-projeto/
├── README.md
├── artigo_TCC.pdf
├── documentacao/
│   ├── requisitos.pdf
│   ├── manual_usuario.pdf
│   ├── manual_desenvolvedor.pdf
│   └── diagramas/
│       ├── ER.png
│       └── UML.png
├── codigo_fonte/
│   ├── backend/
│   └── frontend/
├── banco_de_dados/
│   └── scripts.sql
└── demonstracao/
    └── video.mp4 (ou link_para_video)
```

**Descrição dos Arquivos e Pastas:**

  * `README.md`: Este arquivo, com informações sobre o projeto, dependências e instruções.
  * `artigo_TCC.pdf`: O documento acadêmico final do TCC, formatado conforme as normas da ABNT.
  * `documentacao/`: Pasta contendo a documentação completa do projeto.
      * `requisitos.pdf`: Documento com os requisitos funcionais e não-funcionais.
      * `manual_usuario.pdf`: Manual de instruções para o usuário final.
      * `manual_desenvolvedor.pdf`: Manual para futuros desenvolvedores, explicando a arquitetura e o código.
      * `diagramas/`: Pasta com os diagramas do projeto (por exemplo, Diagrama de Entidade-Relacionamento, Diagrama de Classes UML).
  * `codigo_fonte/`: Contém todo o código-fonte do sistema, separado em `backend` e `frontend`.
  * `banco_de_dados/`: Scripts SQL necessários para a criação e manipulação do banco de dados.
  * `demonstracao/`: Vídeo de demonstração do funcionamento do sistema.
